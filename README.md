# Enigma Score

Проект для скоринга кредитных заявок с использованием машинного обучения.

## Архитектура

Проект состоит из двух основных частей:
- **Backend (Django)** - API-сервер для обработки запросов и предсказания вероятности одобрения кредита
- **Frontend (HTML/JS)** - Простой интерфейс для взаимодействия с API

## Основные компоненты

### Backend (Django)

#### Модели данных (`models.py`)
- **CreditApplication**: Модель для хранения кредитных заявок
  - user: Связь с пользователем
  - loan_amnt: Сумма кредита (с валидацией)
  - loan_int_rate: Процентная ставка
  - person_income: Годовой доход
  - person_emp_length: Стаж работы
  - loan_percent_income: Отношение кредита к доходу
  - person_home_ownership: Тип жилья
  - cb_person_default_on_file: История просрочек
  - loan_intent: Цель кредита
  - probability_default: Вероятность дефолта
  - decision: Решение (APPROVE/REJECT)
  - created_at: Дата создания

- **Profile**: Профиль пользователя с финансовыми данными
  - phone: Телефон
  - birth_date: Дата рождения
  - monthly_income: Ежемесячный доход
  - employment_length: Стаж работы

#### ML-сервис (`ml_service.py`)
- Использует сериализованные модели машинного обучения
- Предсказывает вероятность одобрения кредита на основе:
  - Годовой доход
  - Сумма кредита
  - Процентная ставка
  - Стаж работы
  - Цель кредита
  - Тип жилья
  - История кредитов

#### API эндпоинты (`views.py`)
- `POST /check-credit/` - Проверка кредита и получение предсказания
- `GET /` - Главная страница (авторизованный/неавторизованный)

#### Пользовательская система (`users/`)
- **Регистрация**: Создание нового пользователя с профилем
- **Вход**: Аутентификация пользователя
- **Профиль**: Просмотр и редактирование личных данных
- **Сброс пароля**: Восстановление доступа к аккаунту

### Frontend

#### Главная страница (`index.html`)
- Форма для ввода параметров кредита
- Отображение результата предсказания
- Интерактивные элементы управления

#### Стили (`style.css`)
- Адаптивный дизайн
- Современные CSS-техники (Flexbox, Grid)
- Анимации и переходы

#### JavaScript (`script.js`)
- Валидация формы
- Отправка запросов к API
- Обработка ответов
- Динамическое обновление интерфейса

## Машинное обучение

### Используемые модели
- **Baseline модель**: Простая эвристика на основе правил
- **Продвинутая модель**: Gradient Boosting/XGBoost (в development)
- **Ансамбль**: Комбинация нескольких моделей для повышения точности

### Фичи для предсказания
1. **Финансовые показатели**:
   - Отношение кредита к доходу
   - Процентная ставка
   - Годовой доход
   - Стаж работы

2. **Демографические данные**:
   - Тип жилья
   - Цель кредита

3. **История поведения**:
   - Наличие просрочек по кредитам

## Тестирование

### Фреймворк
Проект использует **pytest** для тестирования с интеграцией Django через `pytest-django`.

### Структура тестов

#### 1. Тесты ML-сервиса (`test_ml_service.py`)
- **Fallback-логика**: Тесты для работы без загруженной ML-модели
  - Проверка формата выходных данных
  - Сценарии одобрения/отказа на основе правил
  - Обработка отсутствующих данных
- **Реальная модель**: Тесты для загруженной ML-модели
  - Проверка формата выходных данных
  - Консистентность threshold (всегда 0.77)
  - Проверка типов возвращаемых данных

#### 2. Тесты представлений (`test_views.py`)
- **Авторизация**: Проверка доступа для неавторизованных пользователей
- **Валидация данных**: Проверка обработки некорректных данных (отрицательная сумма, нулевая ставка)
- **Fallback при ошибках ML**: Проверка работы системы при падении ML-модели
- **Сохранение результатов**: Проверка сохранения заявок в БД и отображения сообщений

#### 3. Интеграционные тесты (`test_integration.py`)
- **Полный поток**: От формы до БД (views → ml_service → preprocessor → модель → сохранение)
- **Различные сценарии**: Маленький кредит/большой доход, большой кредит/высокий риск
- **Обработка ошибок**: Проверка некорректных данных

#### 4. Тесты препроцессора (`test_preprocessor.py`)
- **Заполнение пропусков**: Числовые поля (медиана), категориальные поля (мода)
- **Преобразование данных**: Поддержка словарей и DataFrame
- **Лог-преобразование**: Проверка применения log1p к числовым полям
- **Наличие признаков**: Проверка всех ожидаемых фичей на выходе

#### 5. Тесты пользователей (`users/tests.py`)
- **Регистрация**: Проверка совпадения паролей, дубликатов имен пользователей
- **Вход**: Успешный вход, неправильный пароль, несуществующий пользователь
- **Выход**: Проверка разлогинивания
- **Профиль**: Доступность страницы, обновление данных, связь User и Profile
